# 0004 — Entrega final: zips sin LEEME y dos variantes de interfaz

Fecha: 2026-11-26
Estado: Aceptada (reemplaza el punto 4 de la decisión 0003 en lo que respecta al contenido del zip)

## Contexto
Se hizo una interfaz más moderna para la aplicación. Tiene los mismos campos, botones y distribución que los
wireframes de la Etapa 1. Todavía no está decidido si se entrega esa o la original. Además, el zip de entrega no
tiene que llevar los LEEME de cada etapa.

## Decisión
1. El zip de la entrega final no lleva ningún archivo LEEME.
2. Se arman dos variantes del zip, con el mismo contenido salvo la interfaz:
   - `Entrega Final/Diseño original/`: la que coincide con los wireframes y con el código del repo.
   - `Entrega Final/Diseño nuevo/`: cambia `estilos.css`, `_encabezado.jspf`, `menu.jsp`, `login.jsp` y
     `cuestionario.jsp`.
3. Mientras no se decida, el código del repo queda con el diseño original.
4. Las explicaciones que antes estaban en los LEEME (cómo ejecutar el programa, datos de prueba, correcciones)
   están en `Entrega Final/Apunte para el coloquio.pdf`, de uso interno.

## Consecuencias
- Antes de subir la entrega hay que elegir uno de los dos zips.
- Si se elige el diseño nuevo, conviene pasar esos 5 archivos al repo (están dentro del zip) para que el código
  del repo y el entregado coincidan.
- No cambia ningún diagrama: la interfaz nueva solo cambia el aspecto, no los campos ni el comportamiento.
